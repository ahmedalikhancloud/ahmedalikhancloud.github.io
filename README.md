# Ahmed Ali Khan — portfolio

A static portfolio for AWS cloud, DevOps and platform engineering. Built with semantic HTML, responsive CSS and a small amount of JavaScript. No build tools, paid services, analytics or backend are required.

## Contents

- Introduction and resume download
- Kravel project feature with repository and demonstration links
- Eight architecture diagrams with category filters and a full-size viewer
- Experience, technical skills and education
- Email, LinkedIn and GitHub contact links

## Publish with GitHub Pages

1. Create a **public** repository named `ahmedalikhancloud.github.io`. Initialize it with a README if an assistant will push the site through the GitHub connector.
2. Put this project's files at the repository root. Keep the `assets` folder intact.
3. In **Settings → Pages**, select **Deploy from a branch**, then **main** and **/(root)**. Save.
4. After GitHub completes the Pages build, open `https://ahmedalikhancloud.github.io/`.

This uses GitHub Pages with the included github.io address. No custom domain or AWS infrastructure is needed.

## Edit

- Text, links and architecture entries: `index.html`
- Layout, colors and responsive rules: `styles.css`
- Navigation, filters, diagram viewer and email-copy interaction: `script.js`
- Resume: `assets/AhmedAWSDevOpsResume.pdf`
- Architecture images: `assets/diagrams/`

The diagrams are copies from [Architecture-Diagrams](https://github.com/ahmedalikhancloud/Architecture-Diagrams). Replace the corresponding SVG when a source diagram changes. The walkthrough links always lead to the source repository.

## Preview

Open `index.html` in a browser. On a local file URL, automatic clipboard access may be unavailable; the email link still works. No package installation is required.

## Accessibility and privacy

Includes keyboard navigation, a skip link, visible focus states, reduced-motion support and text alternatives. The diagram viewer uses the native modal dialog with focus returned to its opener. Core content and external walkthrough links remain available without JavaScript. No contact form collects visitor information.

Kravel is identified as a local demonstration. Architecture walkthroughs are representative designs, not records of client deployments. Public copy contains no client names or invented performance metrics.
